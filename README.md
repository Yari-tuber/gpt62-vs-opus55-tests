# GPT-6.2 Sol / Astra 对 Claude Opus 5.5：6 道前端题实测

亚里频道第 026 期视频的全部提示词和作品源码。视频：B 站（待补）· YouTube（待补）

同一份提示词，三个模型各做一遍：

- **GPT-6.2 Sol**、**GPT-6.2 Astra**：本机 Codex CLI 0.170.0，推理强度 xhigh；
- **Claude Opus 5.5**：Claude 桌面客户端，每题开一个新对话，effort xhigh。

2026-11-18（GPT-6.2 发布当天）18 个任务同时开跑，每个只跑一次，作品一个字没改。

## 怎么打开

下载或 clone 下来，双击每个文件夹里的 `index.html`，用 Chrome / Edge 打开就能玩。

- Opus 的鹈鹕、小鹿是从网上加载 three.js 的，要联网才能打开；其余作品断网也能开。
- 3D 作品比较吃显卡，笔记本卡的话把窗口缩小一点。

## 用了多久、花了多少

花费是按各家 API 价折算的，实际用的是订阅，没有按量付费。价格（每百万 token）：Sol 输入 $2 / 缓存 $0.10 / 输出 $10，Astra $8 / $0.40 / $40，Opus 5.5 $4 / 缓存读 $0.20、1 小时缓存写 $8 / 输出 $20。

| 题目 | Sol | Astra | Opus 5.5 |
|---|---|---|---|
| 01 鹈鹕骑自行车 | 20.6 分 · $0.74 | 22.2 分 · $2.06 | 66.4 分 · $12.23（超时） |
| 02 彩虹果冻 | 31.4 分 · $1.17 | 37.7 分 · $4.24 | 77.3 分 · $20.58 |
| 03 小鹿走跑跳 | 32.4 分 · $1.30 | 36.5 分 · $3.93 | 78.5 分 · $17.14（超时） |
| 04 直升机拆装 | 29.6 分 · $1.10 | 36.4 分 · $4.59 | 77.0 分 · $16.31 |
| 05 一句话 3A 射击 | 35.0 分 · $1.19 | 50.3 分 · $5.11 | 75.8 分 · $16.53 |
| 06 《寂寞烟火》MV | 24.9 分 · $1.18 | 40.8 分 · $4.67 | 68.3 分 · $12.81 |
| **合计** | **173.9 分 · $6.67** | **223.9 分 · $24.59** | **443.3 分 · $95.60** |

- 输出 token：Sol 28.5 万、Astra 28.5 万、Opus 222.7 万（大部分是思考）。
- 用时：Codex 是墙钟时间（12 个任务同时跑）；Opus 扣掉了开头几次 API 报错白等的时间。
- 时间上限：鹈鹕、小鹿 60 分钟；果冻、直升机 90 分钟；射击、MV 120 分钟。超时交的标了「超时」。小鹿 Opus 两版都放了：`60分钟时` 是到时间那一刻的版本（视频里按它算），`加时版` 是它最后交的。

## MV 那道题

只放了三家写的代码。歌曲音频、带歌的成片、歌词有版权，没有放进来：代码里写死的歌词每个字都换成了 □（字数不变）。想自己复现，要自己准备这段歌和歌词，详见 [06_寂寞烟火MV/README.md](06_寂寞烟火MV/README.md)。
