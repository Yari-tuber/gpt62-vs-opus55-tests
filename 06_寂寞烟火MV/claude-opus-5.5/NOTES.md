# 《寂寞烟火》（蓝心羽版）1:15.47–1:55.99 · MV 制作说明

成片：`../mv.mp4`（同一份在 `out/mv.mp4`）。1920×1080、60 帧、40.52 秒，H.264 + AAC 256k，配的就是这一段歌（结尾 1.2 秒淡出）。
画面全部由 `scene.js` 里的 canvas 代码逐帧画出来，没有用任何图片、生图、照片或网上素材。

## 这段歌在讲什么、怎么演

跨年夜，一个围红围巾的女孩独自在江边看烟火，想起和「你」□□□□□□□；副歌里她回想为你走过的远路、渡过的海、熬过的黑夜，□□□□□□□人往，你离开时不用说她都懂；最后她对满天烟火说谢谢——镜头拉开，满天烟火和她的身影原来都映在你的眼睛里。

母题是**烟火**，一路变化：一朵（开头）→ 天边一排（进副歌）→ 全灭（黑夜）→ 手里一根仙女棒（想着你）→ 时光里年年的烟火（昼夜轮转）→ 渐灭的一朵（你离开）→ 满天（感谢）→ 你眼中的倒影（结尾）。

逐句怎么演、唱到哪个字画面怎么变，见 `plan.md` 第 4 节；遮住字幕只看图的逐句自查表见 `plan.md` 第 8 节（图：`out/stills/逐句.jpg`）。

## 画风

自己定的「夜色剪影 + 一抹红 + 发光烟火」：
- 人物是关节剪影（侧面 / 背面两套骨架，角度关键帧，走路每拍落一步），只靠轮廓光、姿势和红围巾表达；女孩的侧脸特写有齐下巴短发、碎刘海、睫毛和红围巾，结尾的眼睛是唯一「写实」一点的东西；
- 烟火是自己写的粒子：球形 / 柳 / 环三种，升空拖尾、炸开、下坠、末段闪烁，用 lighter 叠加；同时照亮天空、在江面留倒影、给人物打轮廓光；
- 城市（带一座电视塔，全片同一座城）、星空、银河、山、递归分叉的冬树、六层正弦海浪、路灯、对话框、星轨、昼夜轮转的天、带残影的人潮，都是代码画的零件；
- 字用霞鹜文楷，跟着段落换 karaoke / big / pop / slam / wave 几种上屏方式。

理由：歌名是烟火，夜里的烟火最适合用发光粒子画；抒情歌不需要五官，剪影的姿势（仰头、低头、转身、举手）就够了；红围巾让主角在 40 秒、18 个镜头里每一个都认得出来。

## 时间是怎么对上的

1. 歌词：网上查（百度的歌曲卡片 / 百度百科《寂寞烟火》），再用本机的 Qwen3-ASR-0.6B 听写 vocals.wav，确认这一段是「□□□□□□□□□□□□」+ 第一遍副歌九句（`tools/research/asr.py`、`asr_check/`）。
2. 逐字时间：本机现成的 Qwen3-ForcedAligner-0.6B（`F:/AI-Tools/Qwen3-Subtitle` 里的模型和 Python，没有另装任何东西）用 vocals.wav 强制对齐，约 80 ms 精度。本机字幕服务另外独立跑出来的时间（0.24 / 7.84 / 10.00 秒……）和它一致。
3. 拍子：demucs 分出鼓轨（`stems/`）找拍点，120 BPM（听感是 60 BPM 的慢歌，2 秒一个「小节」= 半个真小节）。
4. **修正**：自动分析把没有鼓的前 8 秒的小节头放偏了半个小节。贝斯轨起音（0.57 / 4.57 / 8.58 s）和军鼓反拍（9.54 + 2k s）都说明真小节头在 0.54 + 2k s，用 `tools/fix_downbeats.py` 改回来（只动 8.5 秒以前，原分析留在 `song.orig.json`）。

## 遇到的问题和解决

- 字幕服务在共用显卡上排队太久 → 直接用它目录里的模型和 Python，在 CPU 上跑对齐（40 秒的歌几秒钟就对完）。
- 第一次对齐时「走」字被拉成 7 秒 → 发现这一段开头还有一句预副歌，补上歌词后对齐正常。
- 天空渐变函数把整张画布都铺满，江面一画就把天和烟火盖住 → 改成只从 y0 往下铺。
- 侧脸特写像光头 → 头发单独上深蓝黑色、加发丝和碎刘海，再压暗，避免像蓝色头盔。
- 「惶恐」的黑影一开始像放射状速度线 → 改成 9 条又粗又弯、带爪子的胳膊，加上黑暗里会眨的眼睛。
- 人潮那一下天是黑的看不清 → 把昼夜轮转的相位排好，让人最多的两拍落在白天。
- 拉远 / 推近镜头会把歌词一起缩放、切掉边 → 歌词统一放到屏幕层。
- ring 冲击波看起来像界面元素 → 去掉，换成 zoomblur / 闪。
- 8 个浏览器进程同时加载时偶发 NetworkError（这台机器同时还在跑别的任务）→ 改成 4 个进程渲染。
