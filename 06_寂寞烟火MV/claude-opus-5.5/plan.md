## 2. 这段歌在讲什么

- 谁在唱、唱给谁：一个刚和「你」分开的女孩，唱给离开的你。
- 发生了什么：跨年夜看着烟火 → 想起□□□□□□□ → 回想为了见你走过的远路、渡过的海 → □□□□□里想着你就不怕 → 时间□□□□□人往，你离开时不用说她□□ → □□□□□她留在你的眼中。
- 情绪：怀念的暖 → 一路奔赴的坚定 → 黑夜里的孤单和勇气 → 离别的释然 → 感激、满天绽放。
- 背景：现代中国城市的跨年夜（整首歌的上一句是「跨年的烟火绽放天空」），冬天，江边。

## 3. 主角和世界（定下来就不改）

- 她：齐下巴的短发 + 碎刘海，A 字长大衣，**红围巾**（全片唯一固定的颜色，远景里一个小红点也认得出）。全身是剪影，靠轮廓光看出形状。
- 你：比她高一点，短发，到腰的夹克，没有颜色。
- 世界：冬夜，深蓝到紫的天，江对岸有一座带电视塔的城市（开头、对岸、□□□□、结尾都是同一座城）。小雪。烟火是唯一的亮色来源。

## 5. 画风

- 风格库：用户没给，按 references/代码画具体东西.md 的基础画风自己定。
- 我选的：**夜色剪影 + 一抹红 + 发光烟火**。理由：歌名就是「烟火」，夜里的烟火最适合用 lighter 叠加的发光粒子画；人物用剪影，靠轮廓光和姿势表达情绪，不需要五官；红围巾让主角在每个镜头里都认得出来。
- 画风卡：
  - 色板：天空 #04061a → #141a44 → #3b2552（地平线带一点暖紫）；剪影 #07060d；红围巾 #e0283b；烟火金 #ffcc78、玫红 #ff70a2、青 #6ed6ff、紫 #b28aff、琥珀 #ff9248；回忆段整体乘一层暖金 #ffd6a0。
  - 材质：平涂剪影 + 发光粒子（径向渐变精灵贴图，lighter 叠加）；全片 4.5% 胶片颗粒 + 0.38 暗角。
  - 线条和形：没有描边，只有轮廓光（同一个剪影用光的颜色偏几个像素先画一遍）。
  - 人和物：关节剪影（髋—膝—踝、肩—肘—手，角度关键帧；走路是正弦循环，每一拍落一步）；城市是矩形楼 + 窗灯 + 一座电视塔；树是递归分叉；海是 6 层正弦浪。
  - 镜头语言：远景交代孤单（人小），侧脸特写交代心事；每个镜头里都有慢推或慢拉，加一点手持呼吸感。
  - 动作节奏：烟火在小节头和拍上炸，脚步踩拍，大时刻是画面本身变（世界换、尺度跳、灯全灭、人变一群）。
  - 字：霞鹜文楷（手写感、温柔），白偏暖、深色描边、暖色辉光；跟着段落换上屏方式。
  - 忌讳：不用照片和生图；不让字挡住她的脸；不用全片同一种打点。
- 零件清单：drawFW 烟火（球 / 柳 / 环）、skyLight 烟火照亮天空、reflectFW 江面倒影、starsCanvas / twinkle 星空、cityCanvas 城市、cityReflect 倒影、ridge 山、treeCanvas / forestLayer 树林、figSide / figBack 她和你（侧面 / 背面）、faceProfile 侧脸特写（短发、睫毛、红围巾、眼泪）、bokeh 虚化光斑、sparkBurst 仙女棒、fearEyes 黑暗里的眼睛、黑影爪子、海浪和小船、路灯、对话框、星轨、昼夜轮转的天、人潮、眼睛（虹膜、瞳孔、倒影、睫毛、眼皮）。
