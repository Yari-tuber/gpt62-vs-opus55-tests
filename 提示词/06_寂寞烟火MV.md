# 寂寞烟火MV

三家用的是同一份提示词，一字不改：

```
当前文件夹里有一首歌《寂寞烟火》（蓝心羽版）的片段 song.mp3，40.5 秒，是这首歌 1:15.47 到 1:55.99 这一段；vocals.wav 是同一段分离出来的人声，给你对时间用。给这一段做一支 MV：
画面全部用代码画，不用生图，不找网上的素材和现成的 MV；歌词可以自己上网查；
1920×1080、60 帧，长度和这段歌一样；
字幕要和演唱对上，画面要跟着音乐的节奏和情绪走，副歌要有高潮；
最后自己渲染出 mv.mp4（带这段歌）。完成度要高。

【规则】只在当前这个文件夹里创建和修改文件；只许上网查这首歌的歌词，不要找现成的 MV、代码或素材，全部自己写。
```
